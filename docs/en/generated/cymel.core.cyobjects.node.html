Function Details:

cymel.core.cyobjects.node.sort(objects, inPlace=False, key=<function keyForBreadthFirst>)¶

Sort the object list.

Basically, a list of objects derived from cymel’s DagNode is assumed, but even if something is mixed up, it will not cause an error and the order will be guaranteed.

Even if Plug is mixed up, it will be a composite sort of DAG node and plug name.

It is provided as an easy-to-use caller, and if the object to be sorted is a list of DagNode, it is more efficient to use the standard sorted or sort method directly and specify the key function.

Parameters:

  • list – List to be sorted.

  • inPlace (bool) – Whether to sort the passed list itself.

  • key – Function that is the basis of the key function for sorting. Assuming that the element is a DagNode derived object, the evaluation of this function and str and id are combined to form the key. You can specify either keyForDepthFirst (DAG node depth is given priority), keyForBreadthFirst (DAG node breadth is given priority), or keyForPathLength (nodes with the same path length are equivalent simply by the depth of the DAG node hierarchy). Default is width first.

Return type:

list
